# 건우 대전쟁

냥코대전쟁풍 GUI로 리디자인한 브라우저 게임입니다.

## 실행 방법

- `index.html` 파일을 다운로드한 뒤 브라우저에서 열면 실행할 수 있습니다.
- 별도의 빌드 과정이나 패키지 설치는 필요하지 않습니다.

## GitHub에 올리는 방법

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`, `README.md`, `.nojekyll` 파일을 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
6. 잠시 기다리면 GitHub Pages 주소에서 게임을 실행할 수 있습니다.

## 참고

- 게임의 기존 JavaScript 로직은 수정하지 않고 GUI 스타일을 변경한 버전입니다.
- 캐릭터 이미지와 게임 데이터는 HTML 파일에 포함된 원본 구성을 따릅니다.
